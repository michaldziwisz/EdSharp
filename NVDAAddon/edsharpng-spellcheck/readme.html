EdSharpNG Spelling Errors

This NVDA add-on makes NVDA announce spelling errors in the EdSharpNG editor, the same way it does natively in Microsoft Word or the browser.

What it does

While EdSharpNG is the foreground application, the add-on checks the text of the editor control with the Windows Spell Checking API and marks misspelled words with NVDA's invalid-spelling attribute. As you read or move through the document, NVDA signals words it considers misspelled, using your Windows spell-check language.

Notes

  • It works on EdSharpNG's editor (a WinForms rich-text control); no EdSharpNG setting is required.
  • It is independent of any built-in spell command: EdSharpNG itself no longer carries a Spell Check menu item, so this add-on is the spelling-feedback path.
  • The spelling language follows Windows' configured spell-checking languages.

After installing

Restart NVDA for the add-on to take effect. To confirm it is active, set NVDA's log level to Debug, open EdSharpNG, and look for an EdSharpNG spellcheck: entry in NVDA's log.
